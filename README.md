# Misprint Department

A 2.5D logic puzzle for iOS and Android. A mechanical command printer keeps
producing route instructions with a systematic printing defect. You know the
defect for the job, so you correct the misprinted commands with a limited set
of bench tools, then pull the proof lever and watch the route run.

- **Engine:** Unity 6000.3.19f1, URP
- **Orientation:** landscape
- **Connectivity:** fully offline. No ads, no analytics, no tracking, no
  accounts, no third-party SDKs.
- **Content:** a guided Training Job plus 12 handcrafted levels in 6 batches,
  each batch teaching one defect family and one correction tool.

## Project layout

```
Assets/
  Scripts/
    Core/     MisprintDepartment.Core   - deterministic engine (no gameplay
              UnityEngine deps): commands, RouteSimulator, DefectRule,
              CorrectionEngine, LevelDefinition, LevelJudge
    Game/     MisprintDepartment.Game    - services, scene glue, audio, and
              all UI behaviours (bind data + toggle state, never build UI)
    Editor/   MisprintDepartment.Editor  - LevelValidator, ChapterBuilders,
              and the Build/ pipeline that regenerates every asset + scene
  Content/Levels/        LevelDefinition assets (Training + Batch01..06)
  Prefabs/ Art/ Audio/   generated by the editor build pipeline
  Documentation/         architecture, design, level design, QA, audits
Assets/Scenes/           Bootstrap, MainWorkshop, Gameplay
```

## Building the project

Open in Unity, then run the menu **Misprint / Build / 0 - REBUILD EVERYTHING**.
It regenerates the material palette, procedural audio + mixer, prefabs, the
app icon, all level assets, the level database, the three scenes, and the
player settings from code.

Validate content: **Misprint / Validate All Levels**.
Run tests: Test Runner, EditMode suite (`MisprintDepartment.Tests.EditMode`).

## Player builds

Windows and Android (IL2CPP / ARM64) player builds succeed from this project.
The iOS build needs macOS and Xcode.
